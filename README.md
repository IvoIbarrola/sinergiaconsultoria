## Tasky

**Tasky** es una aplicación móvil de gestión de tareas que permite a los usuarios crear, organizar y marcar tareas como completadas, con la posibilidad de compartir una lista con otro usuario.

El objetivo principal de la aplicación es ofrecer una herramienta **simple y rápida para organizar tareas de manera individual o colaborativa**. Un usuario puede crear una lista de tareas y compartirla con otra persona, permitiendo que ambos puedan consultar y actualizar el estado de las tareas.

Por ejemplo, Tasky puede utilizarse para organizar tareas del hogar entre dos personas, coordinar actividades de un proyecto pequeño, preparar una lista de compras o simplemente llevar un seguimiento de tareas pendientes.

### Funcionalidades iniciales

- Crear, editar y eliminar tareas.
- Marcar tareas como completadas.
- Organizar tareas dentro de una lista.
- Compartir una lista con otro usuario.
- Permitir que ambos usuarios visualicen y actualicen las tareas compartidas.

La primera versión estará enfocada en mantener una **experiencia sencilla y rápida**, priorizando las funcionalidades esenciales antes de incorporar características más avanzadas.
